# Portfolio Pixel Journey

Asset-only pack for a scroll-driven education story:

1. Student walks with a backpack.
2. Student stops at the MS in the US milestone.
3. Plane and route effects play.
4. Indiana University milestone appears.
5. Student transforms into a graduate and celebrates.

No portfolio source code was changed.

## Quick Preview

Open `preview/asset-preview.png`.

## Formats

- Transparent PNG source sheets
- Individual transparent PNG frames
- Animated WebP loops for modern browsers
- Animated GIF loops for compatibility and quick preview
- Original chroma-key generation sheets under `source-sheets/`

## Recommended Animation Timing

- Student walk: 110 ms per frame
- Student idle: 260 ms per frame
- Student stop and look: 190 ms per frame
- Plane flight and motion trail: 140 ms per frame
- Student-to-graduate transformation: 190 ms per frame
- Graduate celebration: 230 ms per frame
- Cap toss: 170 ms per frame

Use nearest-neighbor scaling and integer display sizes to preserve crisp pixels.
